# 本轮修订

1. 墙根砌石扩展为前、后、左、右四面各两排，并在门口按木柱实际外缘收口。原生工程核验砖块与门框无包围盒重叠。
2. 配乐由用户的 `配乐终版.mov` 通过 macOS 音频导出提取为 M4A，不含视频轨；原始文件保留。页面引用新文件，自动播放尝试、静音及学习暂停行为沿用。
3. 取消树冠整体仿射收窄，恢复原始随机种子生成的完整 24,800 枚叶片及枝条展开。仅 139 枚紧贴实际瓦面的叶片轻微上移，保留原始横向坐标，1 个细枝控制点抬高。原先按屋顶大包围盒清空树冠的核验不再适用；判断以自然轮廓、贴近屋檐和局部瓦面接触为准。

本轮更新主工程和动态 GLB；历史静态成片未重渲染。相关近景与浏览器结果保存在本目录。
