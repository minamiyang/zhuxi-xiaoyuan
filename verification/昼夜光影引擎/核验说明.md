# 昼夜引擎核验

最终结果以《最终运行核验.json》为准。《运行核验.json》记录第一轮测试及连续录屏，当时发现的暂停显示延迟和精确跳帧缓存差异已修复。

- 对全天按一分钟间隔采样，共 1,441 个状态：光照参数均有限，午夜循环端点误差为零。太阳方向、功率、天光、灯光与雾连续计算；六个代表时刻另做实际画面检查。
- 在真实浏览器连续播放完整昼夜，保存《昼夜连续运行.webm》，并提取 1、7、13、17、22、26 秒的有序画面。采用录像抽帧及时间数据核验，没有声称直接以视频理解能力观看了连续视频。录屏为加速检查版，默认网页循环仍为 240 秒。
- 暂停后场景时间与光照时刻保持稳定。时间条、循环速度、静态／动态模式、视角、旋转缩放、图片下载和竖屏已检查。
- 从夕阳跳到夜晚，再以相同场景时间、光照时刻和相机返回，最终测试的画布导出逐像素一致。修复内容包括清除相机惯性、同步暂停状态，以及刷新仍有贡献的补光阴影缓存。
- 当前检查未记录页面／着色器错误；预览网络请求仅访问本地资源。三个新增或修改的 JavaScript 模块语法检查通过。
- 几何与动物路径沿用上一轮已验证版本，本次没有重建建筑或更改游线。
