# 树冠与课文学习模式核验

- 树冠采用完整叶簇的整体仿射调整，保留原生树冠轮廓；24,800 枚叶片，未按屋瓦边界裁剪。正面最终画面为 `crown-front-final.png`。
- 最终动态模型中，484,800 个树冠与枝条三角形在最大风摆包络下与屋顶包围盒无交叠；最小侧向剩余间隙 0.198 米，无非法坐标。
- 页面仅有自由探索、课文学习两个模式。学习时锁定交互相机，返回探索时恢复视角并启用旋转缩放。
- 八段课文在逐句分割后拼接与原文完全一致。正常速度含入镜与句间停顿约 249.5 秒，可选 0.8／1／1.2 倍推进。
- 实际浏览器验证自动跨段、暂停（等待期间进度变化 0）、跳段、速度调整、末段结束和重读；控制台和资源请求无错误。详见 `ui-check.json`、`flow-check.json`。
- 浏览器允许有声自动播放时，音频在未点击页面前已实际开始播放；默认阻止策略下显示开启按钮，首次页面交互后可播放。静音按钮同时改变音频的实际 muted 属性。
- 用户提供音频与本地嵌入副本逐字节一致，时长约 304.7 秒，循环播放。朗读暂停与后台隐藏均暂停配乐，恢复时续播。
- 在 1440×1000 与 390×844 检查文字和模型布局；窄屏无横向溢出，全文可在段落区域滚动。
- 学习是预设节奏的配乐朗读引导，不含语音识别，不依据学生实际声音跳段。
- 新增春笋为网页内自建几何，未加入静态 Blender 工程。昼夜、风动和动物动作继续由网页主时钟驱动。
